# Contributing

Thanks for wanting to help. KI einfach verstehen lives from readers who spot
what the authors missed: a wrong fact, a passage that doesn't land, a missing
source. [Deutsch: siehe unten](#deutsch).

## Issues first, not pull requests

This repository is a **generated mirror**. The website is developed in a
private project repository (which also holds the e-book and video scripts),
and every release overwrites this repository with a fresh copy of the
`packages/website` folder. That has two consequences:

- **Pull requests can't be merged here.** A merge would be overwritten by
  the next release.
- Every lesson goes through a review process (sources, comprehension,
  language) before it is published. Changes to content have to go through
  that process too.

So please **open an issue** instead. If your report or suggestion is taken
up, the change is made in the source repository, released with the next
update, and your contribution is credited on the corrected lesson. Small
code fixes are welcome as a pull request *after* talking about them in an
issue; they are then carried over by hand, with credit.

## Where does what go?

| You want to … | Go to |
| --- | --- |
| report a mistake in a lesson (fact, unclear passage, typo, missing source) | [Issue: Error in a lesson](https://github.com/silvio-l/ki-einfach-verstehen-website/issues/new?template=fehler-im-baustein.yml) |
| suggest an improvement or a new graphic | [Issue: Suggestion](https://github.com/silvio-l/ki-einfach-verstehen-website/issues/new?template=verbesserungsvorschlag.yml) |
| ask a question about the content | [Community forum](https://community.ki-einfach-verstehen.de) |
| report a bug on the website (layout, demo broken, …) | [Issue: Suggestion](https://github.com/silvio-l/ki-einfach-verstehen-website/issues/new?template=verbesserungsvorschlag.yml), mention browser and device |

Each lesson on the website also has a "report an error" link that fills in
the lesson and section for you.

## Good reports

- Name the lesson and the passage (heading or a short quote).
- Say what is wrong and what would be right.
- Add a source where you can: a paper, documentation, a textbook.
- One problem per issue.

Be friendly and assume good intent. Everyone here is learning, including the
authors. See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## Deutsch

Danke, dass du mithelfen willst! Am meisten hilft es, wenn du Fehler,

- **Erst ein Issue, kein Pull Request.** Dieses Repository ist ein

- **Lizenz deiner Beiträge:** Inhalte unter [CC BY 4.0](LICENSE-CONTENT.md),
  Code unter [MIT](LICENSE).
- **Umgang:** freundlich und wohlwollend, siehe [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
